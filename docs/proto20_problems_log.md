# Problems we found and how we solved them

A plain-language log for the student: every real problem found while building the 20-stock prototype, how it was found, and what we did about it. It's meant for presenting ("how do you know your numbers are right?"). The technical records are in `decisions.md` (known issues) and `decisions_20.md` (decisions D38 onward). This log is updated every phase.

**The lesson that repeats:** most problems were found by checking a result against something we already knew (the real top-20 list, the benchmark, a hand calculation, a transcript), not by the code crashing. When a number looks a little off, find out why.

| # | Phase | Problem | How we found it | What we did | Status |
|---|---|---|---|---|---|
| 1 | P0 | The first "top 20 companies on 4 Jan 2021" list was wrong. Old 3-month price files from the trial were reused for the whole period, some stock splits were missing, and some companies had no share count | Compared the list with the well-known biggest companies of early 2021 | The downloader now checks that a saved file covers the dates asked for. We saved the full split history and added backup sources for share counts. Tests added | Fixed |
| 2 | P1 | Pinduoduo (PDD) was filed under "Industrials" because of its official US industry code | It was the only Industrials company in the 20, so the ±2-point sector rule would have frozen its weight | Treated as Consumer Discretionary (an online shop, like Amazon), recorded as decision D47 | Fixed |
| 3 | P1 | Foreign companies trade in the US as "receipts" that can stand for several shares, so their size came out wrong | Their market values did not match public figures | A hand-checked table of receipt ratios (`reference/adr_ratios.csv`) | Fixed; JD and PDD ratios to be double-checked by the user |
| 4 | P2 | Chinese and European companies' figures (in yuan or euros) were shown with a "$" sign, and a price/earnings ratio was computed across currencies | Read the first memo inputs before sending them to the AI | Each figure now shows its own currency; P/E only for US-dollar filers | Fixed |
| 5 | P2 | Apple's headquarters showed as "unknown"; news text had codes like `&amp;` | Same read-through | Fixed the missing-value check; decoded the news text | Fixed |
| 6 | P2 | The cost report counted tokens twice when an answer came from the saved cache | Totals didn't match the bill | Token columns now count real API calls only | Fixed |
| 7 | P2 | All 8 trial memos said "neutral, low conviction" | Read the memos | Not a bug: the junior analysts were told to be careful. Watched in P4 (the committee does take positions) | Noted |
| 8 | P3 | "Hold the benchmark" ended 2 points behind the benchmark, but it should match it almost exactly | Comparison against the benchmark | After a stock split (Alphabet and Amazon, 20-for-1 in 2022), the share count stayed at the old figure until the next quarterly report, so those companies looked 20× too small for weeks. Share counts are now adjusted for later splits. Gap now 0.3 points; tests fail without the fix | Fixed |
| 9 | P4 | The risk-free (T-bill) rate stopped in July 2015, so Sharpe ratios after that would have been wrong | Checked the data range before building the reports | Same cause as #1, in another downloader. Fixed the date check and re-downloaded 2014–2024 | Fixed |
| 10 | P4 | Bob's simulated trading crashed in the first month of the paid trial | The trial stopped with an error | Its 12-month look-back reached before the first stored price. Months without prices are now skipped; test added | Fixed |
| 11 | P4 | A table said a strategy "beat the index in 1 of 12 months" when it actually had no data in 11 of them | Read the briefing | Added a "months with a signal" column | Fixed |
| 12 | P4 | The AI service's discount for re-reading the same text ("prompt caching") wasn't working: each committee member re-sent the 10,000-token briefing at full price | Token report: cache reads were 0 | Each member had a different answer format, and the format counts as part of the cached text. One shared format for all five; committee cost down about 40% (about $8 saved over the final runs) | Fixed |
| 13 | P4 | Answers for 20 companies could have been cut off at the length limit | Answers for 5 companies were already about 1,000 tokens | Reasons limited to about 25 words; limit raised to 6,000 tokens | Fixed |
| 14 | P4 | The optimizer turned Otto's "NVIDIA ×1.0, American Airlines ×0" into NVIDIA ×2.0 and American Airlines ×1.16, the opposite of what he asked | Read the trial's transcript | Corrections were shared as equal percentage points, which is huge for a small company. Now shared in proportion to size (decision D50, chosen by the user) | Fixed |
| 15 | P4 | One rerun that was meant to be free (from the cache) cost $0.01, without approval | The cost line | The optimizer change (#14) had changed the portfolio, so the AI was asked new questions. Process fix: check that a run is cache-only before starting it | Fixed (process) |
| 16 | P4 | The committee's track record said "60% right" in 2021, which looked better than it was | View-accuracy table: overweights and underweights both lagged the benchmark | In 2021 the biggest companies led the market, so most smaller stocks lagged whatever the committee thought. We report this caveat with every result | Noted |
| 17 | P5 | Enhanced version: Otto said "buy NVIDIA" and the weight went to zero | Read the trial's transcript | The full mean-variance optimisation also moved companies without a view. Changed to the standard He & Litterman form: start from the benchmark, tilt only the rated companies, then apply the same rules as the baseline | Fixed in code; to be confirmed by a rerun |
| 18 | P5 | Enhanced version: with the default settings, every buy pushes a weight to the 2× limit and every sell to 0×, whatever the confidence, so the portfolio trades 40–50% a month | A unit test ("more confidence moves the weight further") failed: confidence 0.2 and 0.8 gave the same weight | Options given to the user (13 Nov): scale all bets to a fixed risk budget (recommended), keep the defaults, or shrink the rating table | Waiting for the user's choice |
